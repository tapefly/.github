## Product

TapeFly is a deterministic fruit-fly game built on TapeOut circuits. The official
50-gate brain is live as circuit `#1` on BNB Chain and answered all 4,096 possible
on-chain checks identically.

- [Live product](https://tapefly.xyz)
- [Main repository](https://github.com/tapefly/tapefly)
- [Documentation](https://tapefly.xyz/docs)
