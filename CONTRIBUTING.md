# Contributing to TapeFly

TapeFly is developed in
[tapefly/tapefly](https://github.com/tapefly/tapefly). Its
[CONTRIBUTING.md](https://github.com/tapefly/tapefly/blob/main/CONTRIBUTING.md)
contains the development setup, compatibility rules and pull-request checklist.

The essentials:

- Never commit a private key, seed phrase, API secret or `.env` file.
- Do not make a historical replay, seal, season or circuit claim pass by weakening its test.
- Keep live, planned and archived capabilities clearly separated.
- Run the checks that cover what you changed.
- Report vulnerabilities privately according to [SECURITY.md](./SECURITY.md).

Be direct about the code and evidence, and respectful to the people involved.
